# Horsey Docs

This folder is the project-level home for planning, product decisions, and implementation notes that span the frontend and backend.

## Folders

- `priorities/` - Living priority lists, product direction, and implementation to-do documents.

## Key Docs

- `local-development.md` - How to run the app locally and diagnose startup issues.

## Planning Conventions

Use dated, numbered documents for major planning notes:

```text
docs/priorities/0001-core-product-priorities.md
docs/priorities/0002-matchmaking-hardening.md
```

Each planning document should include:

- Current status
- Product intent
- Priority list
- Risks or open questions
- Next implementation steps

Keep these documents practical. They should help decide what to build next, what to defer, and why.
